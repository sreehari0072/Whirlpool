## Project Description

**Goatlife.com** is a completely useless and unnecessarily entertaining website where a hungry virtual goat eats whatever the user types.

The goat starts off sleeping peacefully. Once the user begins typing, the goat wakes up, walks toward the text, and starts eating the words from the right side. As it eats, its stomach grows bigger. After getting tired, the goat walks back, burps, and eventually returns for another meal.

In short, we created a website that solves a problem that never existed. 🐐

---

## The Problem (that doesn't exist)

People can type peacefully without being interrupted by a hungry goat.

We identified this as a serious problem that absolutely nobody asked us to solve.

---

## The Solution (that nobody asked for)

We introduced a hungry virtual goat that follows the user's typing.

It:

* 🐐 Wakes up when the user starts typing
* 🚶 Walks toward the text
* 🍴 Eats the typed words
* 🫃 Gets a bigger stomach as it eats
* 😴 Gets tired after eating
* 🚶 Walks back
* 💨 Burps
* 🔄 Returns for another meal

Because apparently, normal typing wasn't difficult enough.

## Project Documentation

### How It Works

The website consists of an interactive text input and an animated virtual goat.

The basic interaction works as follows:

1. The goat starts in a sleeping state.
2. The user begins typing into the text area.
3. JavaScript detects the user's input.
4. The goat wakes up and starts moving toward the text.
5. The typed words are gradually removed/eaten from the right side.
6. The goat's stomach visually grows as it eats.
7. After consuming enough text, the goat becomes tired.
8. It walks back and performs a burping animation.
9. The goat eventually becomes ready to eat again.

The project combines JavaScript logic with CSS animations to create the interactive experience.
